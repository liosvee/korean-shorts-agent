# Produce and review

Read docs/production.md. Check the approved script, translation, voice and
media budget. Use the real narration voice ID and explicit model. Prepare
speech.plan.json using speech-plan; review all requests before submission.
No guessed credit rates. Keep a dated source for each estimate.

Submit each approved generation once in its own new job directory. For unknown
outcomes, reconcile existing provider records; do not retry a paid POST.
Generate new visual assets using reviewed requests, or use locally supplied
assets with documented permissions. Canva/stock downloads are manual or through
separately configured tools; there is no built-in stock or Canva integration.

Measure the narration, adjust scene timings, then render a 1080x1920 MP4 using
an explicit Korean font file. Captions come from actual provider alignment,
not guessed reading speed. Refine automatic cue splits for natural Korean
phrasing without changing the measured timing. Preserve original alignment.

Inspect actual frame samples, watch and listen to the complete export. Check
pronunciation, meaning, missing glyphs, reading speed, safe placement, cuts and
audio balance. Request a fluent Korean review when naturalness cannot be
reliably assessed. Mark unresolved language review honestly. Render technical
checks alone do not prove editorial quality. Save qa.md with checks and limits.

Deliver the MP4, captions, Korean packaging, English translation, provenance
and source report. Do not publish. Save the final status for resumption.
